应用概览

仓库：my-nextjs-app

它是什么

这是一个基于 Next.js 16 的 Web 应用，把一组浏览器端小工具和若干服务端能力整合在同一个站点里。

从仓库结构看，它更像一个“个人/内部工具箱”，而不是单一用途产品。

面向谁

主要面向开发者或技术运营人员，他们需要一个轻量的网页入口来处理文本/数据工具、发送邮件、做受保护的 AI 知识库问答，以及进行简单实时沟通。

它做什么

  • 提供 JSON 格式化、Base64、文本对比、时间换算、数据过滤、EML 查看、Brainfuck、计算器等工具页。
  • 支持上传 TXT、MD、PDF 文档，建立知识库并通过 AI 问答接口检索回答。
  • 提供登录、注册、邮箱验证码、图形验证码、JWT 会话，以及管理员用户管理能力。
  • 提供基于房间 Token 的实时聊天室，消息入库后通过 SSE 推送到在线客户端。
  • 支持通过 Gmail SMTP 发信，包含基础校验、附件处理和内存级限流。
  • 提供定时邮件接口，可附加 BTC 快照与价格图表。

如何运行

  • 准备 `.env`：至少需要 `PRISMA_DATABASE_URL` 和长度不少于 32 的 `JWT_SECRET`。
  • 如需 AI 功能，补充 `GOOGLE_API_KEY` 或 `OPENAI_API_KEY`。
  • 如需邮件功能，补充 `GMAIL_USER` 与 `GMAIL_APP_PASSWORD`。
  • 安装依赖：`npm install`
  • 初始化 Prisma：`npm run prisma:generate` 与 `npm run prisma:migrate`
  • 启动开发环境：`npm run dev`，然后访问 `http://localhost:3000`

如何工作

前端页面位于 `app/*`，API 路由位于 `app/api/*`。`middleware.ts` 会保护 `/ai-qa` 与 `/api/ai-qa`，通过 `session` Cookie 解密 JWT 判断是否已登录。

服务端通过 Prisma 连接数据库，当前 schema 中可见 `User`、`VerificationToken`、`ChatMessage`、`DocumentChunk` 等表。

AI 入库流：上传文件 -> 解析 PDF/文本 -> 分块 -> 生成 embedding -> 存入 `DocumentChunk`。

AI 问答流：对问题做 embedding -> 与已存向量做余弦相似度排序 -> 拼上下文 -> 调用 Gemini 或 OpenAI 模型生成回答。

聊天流：前端 POST 消息 -> Prisma 入库 -> 进程内 SSE bus 通知 -> `/api/chat/stream` 推送历史和新消息。

邮件流：页面或定时任务调用 API -> 参数校验与限流 -> Nodemailer 使用 Gmail SMTP 发信。
